# FleetTrack Monitor

Real-time fleet management and vehicle tracking web application.

## Features

- Real-time vehicle tracking
- GPS-based location monitoring
- Fleet management dashboard
- Trip management
- Driver management
- User authentication
- Admin verification
- Live fleet monitoring
- Responsive web interface

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Node.js
- GPS / Geolocation APIs

## Project

FleetTrack Monitor provides a centralized platform for monitoring vehicles, managing trips, and tracking fleet activity in real time.
